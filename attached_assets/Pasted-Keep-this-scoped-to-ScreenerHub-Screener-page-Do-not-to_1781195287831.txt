Do not show raw debug fields as badges.

Show a small plain-English status only when useful:

If theme_refresh_status is:

refreshing → show “Refreshing theme data…”
refresh_queued → show “Refresh queued”
stale_cap_active → show “Using cached theme data”
refresh_failed → show “Theme refresh failed”
weak_cache → show “Limited cached data”

theme_last_refreshed_at
theme_next_refresh_allowed_at
