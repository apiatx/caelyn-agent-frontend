Performance requirements:

1. Do not mount all charts in an expanded group at once if the group is large.

   * Initial render per expanded group should be 4–6 charts max.
   * “Load more” should add 4–6 more.
   * Do not render hidden charts.

2. Use viewport lazy mounting:

   * Only mount the iframe when its card is near visible using IntersectionObserver or an existing lazy-render pattern.
   * Before visible, show a lightweight placeholder card with ticker/theme.
   * Once visible, mount the iframe.

3. Prevent iframe remount loops:

   * Ensure iframe React key is stable.
   * Key should be something stable like `${ticker}-${interval}`.
   * Do not include object references, group object, random IDs, Date.now(), or changing layout state in iframe key.
   * Changing filters/group expand should not remount already-visible iframes unless symbol/interval actually changes.

4. Default state:

   * Only first group expanded, or all groups collapsed.
   * First expanded group should render only first 4–6 visible charts.
   * Collapsed groups must not mount iframes.

5. Symbol handling:

   * Use symbol.tradingview_symbol when provided.
   * If it is bare ticker, pass it exactly as-is.
   * Do not double encode `NASDAQ:AAOI`.
   * Do not strip exchange prefix.
   * Do not lowercase.
   * Do not transform symbols differently from MultiCharts.

   * whether each iframe mounted because it became visible
