- theme_name

- sector_alignment
- macro_fit
- regime_alignment_score
- thematic_badges
- dead_zone_warning
- base_composite_score

- theme_name
- theme_state
- regime_alignment_score
- regime_alignment_label
- thematic_badges
- dead_zone_warning
- base_score

- regime_context

Goal:
Display these new fields without breaking existing UI or response handling.

Guardrails:
- Do not change Earnings.
- Do not change backend.
- Do not remove existing scores.
- Do not hard-require the new fields; they are optional.
- If fields are missing, existing UI should behave exactly as before.
- Keep this additive and visually clean.
