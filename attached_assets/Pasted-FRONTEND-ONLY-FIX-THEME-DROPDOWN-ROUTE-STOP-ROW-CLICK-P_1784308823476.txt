Theme dropdown still does not work.

1. Selecting a theme throws:

Failed to execute 'json' on 'Response': Unexpected token '<', "<!DOCTYPE "... is not valid JSON

This means the frontend request is receiving HTML, not JSON. Likely causes:
- wrong frontend URL
- Express proxy route not registered
- Express proxy route placed after Vite fallback
- method/path mismatch
- proxy route returning HTML fallback instead of backend JSON
- frontend fetch blindly calls response.json() on non-JSON response

This means dropdown click/select events are bubbling to the row/ticker click handler.

3. Theme should update immediately in the Theme column when selected.

Fix only the theme dropdown.

Selecting a theme should:
- not open ticker popup
- optimistically update the row immediately
- call the correct backend proxy endpoint
- receive JSON, not HTML
- persist after refresh
- rollback on failure

==================================================

- return backend JSON exactly

  }

Frontend must never try to parse HTML as JSON without checking.

Acceptance:

==================================================
PART 3 — FIX FRONTEND FETCH / MUTATION ERROR HANDLING
==================================================

In the theme assignment mutation, do not blindly call response.json().

Use safe parsing:

const contentType = response.headers.get("content-type") || "";

if (!contentType.includes("application/json")) {
  const text = await response.text();
  throw new Error(`Theme update returned non-JSON response: ${response.status} ${text.slice(0, 120)}`);
}

const data = await response.json();

if (!response.ok) {
  throw new Error(data?.detail || data?.error || "Theme update failed");
}

Make the error toast user-friendly:

"Could not update theme. Try again."

But log the technical response in dev console for debugging.
