Auth — How It Works
The backend uses JWT tokens stored in localStorage under the key caelyn_jwt.

Important: Auth is currently disabled server-side — all API endpoints respond to any request, no token needed. However, wire it in correctly so when auth is re-enabled, nothing breaks.

Step 1 — Login (call once, store the token):

const res = await fetch(`${BACKEND}/api/auth/login`, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ username: 'admin', password: 'YOUR_PASSWORD' })
});
const { token } = await res.json();
localStorage.setItem('caelyn_jwt', token);

Step 2 — Every subsequent API call must include the token:

function authHeaders() {
  const token = localStorage.getItem('caelyn_jwt') || '';
  return {
    'Content-Type': 'application/json',
    ...(token ? { 'Authorization': `Bearer ${token}` } : {})
  };
}
// Example call
const data = await fetch(`${BACKEND}/api/home/dashboard`, {
  headers: authHeaders()
}).then(r => r.json());

Step 3 — On 401, re-login (for when auth gets re-enabled):

async function apiFetch(path, options = {}) {
  const res = await fetch(`${BACKEND}${path}`, {
    ...options,
    headers: { ...authHeaders(), ...(options.headers || {}) }
  });
  if (res.status === 401) {
    localStorage.removeItem('caelyn_jwt');
    // redirect to login page or show login modal
  }
  return res;
}

Streaming endpoint (/api/query)
This returns Server-Sent Events (SSE), not JSON:

const res = await fetch(`${BACKEND}/api/query`, {
  method: 'POST',
  headers: authHeaders(),
  body: JSON.stringify({ message: 'your question here' })
});
const reader = res.body.getReader();
const decoder = new TextDecoder();
while (true) {
  const { value, done } = await reader.read();
  if (done) break;
  const text = decoder.decode(value);
  // parse SSE: lines starting with "data: "
  for (const line of text.split('\n')) {
    if (line.startsWith('data: ')) {
      const payload = line.slice(6);
      if (payload === '[DONE]') break;
      // append payload to UI
    }
  }
}

Summary of what to replace
Any hardcoded old .replit.app URL → replace with the new backend URL from the Deploy tab
All fetch('/api/...') calls (relative) → prefix with BACKEND constant
Auth header → always include Authorization: Bearer ${localStorage.getItem('caelyn_jwt')} when the token exists
Token refresh → if you get a 401, clear localStorage and show the login flow
