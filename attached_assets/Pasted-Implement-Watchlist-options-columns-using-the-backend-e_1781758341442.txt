Implement Watchlist options columns using the backend endpoint that is now validated.

Backend endpoint:
`GET /api/watchlist/{id}/options-signals`

Response shape:

```ts
{
  signals: {
    [ticker: string]: {
      ticker: string;
      options_score?: number;
      options_signal?: string;
      options_put_call_ratio?: number;
      options_iv?: number;
      options_expected_move?: number;
      options_volume?: number;
      options_open_interest?: number;
      options_call_volume?: number;
      options_put_volume?: number;
      options_stale?: boolean;
      options_data_available?: boolean;
      options_risk_score?: number;
      options_risk_level?: string;
      options_source?: string;
      options_unavailable_reason?: string;
      options_updated_at?: string;
    }
  };
  options_meta: {
    symbols_requested: number;
    cache_hits: number;
    master_hits: number;
    lkg_hits: number;
    cache_misses: number;
    live_calls_enqueued: number;
    already_inflight: number;
    scan_in_progress: number;
    rate_limited_or_deferred: number;
    scope: "watchlist";
    ttl_seconds: number;
    elapsed_ms: number;
  };
}
```

Hard constraints:

* Do NOT touch the Options Flow page.
* Do NOT touch Portfolio Terminal behavior.
* Do NOT make any Tradier calls from the frontend.
* Do NOT create a new Watchlist options section.
* Add options fields as columns inside the existing Watchlist Tickers section/table.
* Close Watch/favorites must automatically show the same columns because it uses the same ticker table data.
* Do not block the Watchlist page while options data is building.

Implementation:

1. Add a React Query call in Watchlist page:

```ts
const { data: optionsResp, isLoading: optionsLoading } = useQuery({
  queryKey: ['watchlist-options-signals', activeId],
  queryFn: async () => {
    const r = await fetch(`/api/watchlist/${activeId}/options-signals`);
    if (!r.ok) throw new Error(`watchlist options: ${r.status}`);
    return r.json();
  },
  enabled: !!activeId && (innerView === 'tickers' || innerView === 'close-watch'),
  staleTime: 120_000,
  refetchOnWindowFocus: false,
  retry: 1,
});
```

2. Build:

```ts
const optionsSignalsByTicker = optionsResp?.signals ?? {};
const optionsMeta = optionsResp?.options_meta;
```

3. Merge options data into ticker rows after realtime quote hydration:

```ts
const mergedTickers = useMemo(() => baseMergedTickers.map((t) => {
  const sym = (t.ticker || '').toString().toUpperCase();
  const rt = sym ? realtimeQuotes[sym] : undefined;
  const quoteMerged = rt ? mergeRealtimeQuote(t, rt) : t;
  const opt = sym ? optionsSignalsByTicker[sym] : undefined;
  return opt ? { ...quoteMerged, ...opt } : quoteMerged;
}), [baseMergedTickers, realtimeQuotes, optionsSignalsByTicker]);
```

Important:
If `mergeRealtimeQuote()` strips unknown fields or returns a narrow object, update it so it preserves all original row fields. Options fields must not disappear when live quotes update.
