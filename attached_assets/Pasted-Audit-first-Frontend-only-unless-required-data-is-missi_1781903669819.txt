Average daily % calculation:
Use the existing loaded per-row daily change % field.

Possible aliases:

* change_percent
* changePct
* change_pct
* changesPercentage
* day_change_percent
* price_change_percent
* chg_percent
* chgPct

Create a shared helper:

* getDailyChangePct(row)
* avgDailyChangePct(rows)

Rules:

* Only include valid numeric values.
* Ignore null, undefined, empty string, NaN, and non-numeric values.
* Do not count missing values as 0.
* 0 is valid and should be included.
* Average should be arithmetic mean of listed tickers in that bucket.
* Use only tickers actually displayed/listed in that bucket.
* If no valid values exist, show `—`.

Formatting:

* positive: `+1.23%`
* negative: `-1.23%`
* zero: `0.00%`
* missing: `—`

Color:
Use existing green/red/neutral styling:

* positive green
* negative red
* zero/missing muted

Important:
For Fundamental Grouping, average the tickers actually listed in each bucket, not omitted watchlist tickers.

For Market Cap Grouping, average all tickers listed in that market-cap bucket.

For Theme Grouping, average all tickers listed in that theme bucket.

Active watchlist:
All calculations must respect the currently selected saved watchlist:

* Primary
* Close Watch/Favorites
* future saved watchlist tabs

Do not calculate averages from Primary when another watchlist tab is active.

Do not fetch:

* FMP
* Tradier
* options endpoints
* backend refresh endpoints
* LLMs

Reuse existing data only.

Implementation guidance:
Create one shared helper for bucket performance:

const getBucketAvgChange = (rows) => {
const vals = rows
.map(getDailyChangePct)
.filter(isValidNumber)
if (!vals.length) return null
return vals.reduce((a, b) => a + b, 0) / vals.length
}

Then use it in:

* Fundamental Grouping bucket headers
* Market Cap Grouping bucket headers
* Theme Grouping bucket headers if needed

Do not create three separate average formulas.
