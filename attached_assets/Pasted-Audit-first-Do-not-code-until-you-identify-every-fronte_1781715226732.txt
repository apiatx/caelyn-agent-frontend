Primary bug:
Dashboard correctly shows stocks + options, but Terminal and Fundamentals visually still behave like the portfolio only has stock positions. Frontend must now consume the canonical backend fields instead of deriving stock-only counts/symbols locally.

Rules:

1. Do not redesign the page.
2. Do not invent a new portfolio model.
3. Do not duplicate backend aggregation math locally unless the existing frontend already has no backend field for the exact UI value.
4. Do not count option contracts as positions.

   * 8 option rows = 8 positions.
   * 166 contracts is not the portfolio position count.
5. Use option underlyings for fundamentals/news/context lookups.
6. Never pass OCC option contract symbols into stock/fundamental/news lookups.
7. Do not confuse actual user option holdings with the existing Options Flow scanner table. They are different things.
