==================================================
COLUMN DEFINITIONS
==================================================

Ticker:
- Symbol
- Company name if already available

Confluence:
- Show caelyn_confluence_score
- Display as “Score”, not percent
- Max is 125
- Also show core_score + bonus_score in tooltip:
  Core: X / 100
  Bonus: Y / 25

Decision:
- Use actionability_state
- Do not derive from score
- Badge examples:
  READY
  NEAR_ACTIONABLE
  WATCH
  WATCH_FOR_RESET
  AVOID
  RISK_CONFLICT

Setup:
- Show technical_setup_label
- Show technical_setup_points / 8
- Tooltip should show technical_setup_reason_codes if available

Theme:
- Show theme_alignment_points / 15
- Show theme name / theme label if available
- Include theme policy only as part of theme tooltip, not standalone bonus

Options:
- Show options_alignment_points / 20
- Show options_status
- If options_status = available_cached, show normal
- If confirmed_no_options, show “No listed options”
- If not_scanned, show “Queued” / “Not scanned” using:
  options_not_scanned_reason
  options_scanner_queue_status
  options_backfill_priority
  options_scanner_scope_reason
- Do not treat not_scanned as bearish

Entry / Exit:
- Show entry_exit_points / 12
- Show entry_exit_status
- If level fields exist, show support/resistance/target/invalidation in tooltip
- Do not invent target levels if null

Catalyst:
- Show catalyst_alignment_points / 15
- Show direct_catalyst_type if present
- Show catalyst_lkg_source in tooltip
- If catalyst LKG is warming or unavailable, show neutral/warning state, not bearish

Investment:
- Show investment_alignment_points / 15
- Show investment_quality_label
- Show pillar count:
  0 / 3
  1 / 3
  2 / 3
  3 / 3
- Show pillar badges:
  Financial Health
  Current Growth
  Forward Growth

Bonuses:
- Show combined bonus:
  social_bonus_points
  whale_insider_bonus_points
  bottleneck_bonus_points
- Whale/Insider currently may return not_wired. If not_wired, grey it out or hide from the visible bonus chips.
- Do not display Whale/Insider as active unless whale_insider_status indicates active/available.
- Bottleneck should show anchor count if available.
- Social should show section hits if available.

Confidence:
- Show caelyn_confluence_confidence_score
- This is data completeness, not score strength.
- Tooltip:
  “Confidence reflects completeness/trustworthiness of available data, not bullishness.”

==================================================
VISUAL RULES
==================================================

Confluence score:
- Do not show as percent.
- Show as “68.6 / 125” or just “68.6” with tooltip “max 125”.

Decision:
- More prominent than bucket.
- Bucket can be secondary.

Options:
- available_cached = normal
- confirmed_no_options = neutral
- not_scanned + queued_high_priority = pending/queued
- prefixed_foreign_or_otc_symbol = excluded/non-standard
- Do not make missing options look bearish.

Whale/Insider:
- If whale_insider_status = not_wired, do not show as active.
- Optional grey chip: “Whale/Insider not wired yet.”

Catalyst:
- If catalyst_lkg_source = disk_lkg or memory, show normally.
- If unavailable_cold_start, show “Catalyst warming” not bearish.
