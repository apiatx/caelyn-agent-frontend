PART 7 — LIVE EVENT SELECTION INSIDE THE POPUP

The popup already receives:

detail.earnings_intelligence.live_event

The global feed may contain a newer version of the same event.

Create one selector that:

1. Finds the feed event matching the open ticker.
2. Compares the real revision / updated timestamp / state fields.
3. Uses the newer matching feed event when it is newer.
4. Falls back to ticker-detail live_event.
5. Returns null when neither exists.

This lets an open popup update promptly without another ticker-detail request.

Do not mutate historical earnings data.

Do not replace the full ticker-detail payload with the feed response.
