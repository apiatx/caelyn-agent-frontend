Treemap rendering:
Render tiles in an SVG sized exactly to the panel:

* svg width = measuredWidth
* svg height = measuredHeight
* viewBox = `0 0 ${measuredWidth} ${measuredHeight}`
* treemap.size([measuredWidth, measuredHeight])

Each tile:

* render as `<g transform="translate(x0,y0)">`
* render `<rect width={x1-x0} height={y1-y0}>`
* render text only when tile is large enough
* tiny tiles rely on hover/click tooltip

This removes CSS transform drift and keeps all coordinates inside one known coordinate system.

Squareness / aspect ratio:
Use d3.treemapSquarify with a sane ratio.

Target:

* tiles should be square-ish like TradingView
* avoid extreme runway rectangles
* use paddingInner/paddingOuter carefully, no huge gaps
* do not allow one tile to create useless blank space

Important:
The treemap should fill the full rectangular panel. Any black gap larger than a few pixels at the bottom/right is a bug.

Sizing logic:
Do not size by raw net premium alone.
Do not size by pure P/C deviation alone.

Use combined signal:

safePcr = clamp(premium_pcr ?? put_call_ratio ?? pcr ?? pc_ratio ?? 1, 0.01, 100)
pcrDeviation = abs(log(safePcr))

grossPremium = call_premium + put_premium
If grossPremium is missing or zero, fallback to abs(net_premium).

materiality = log1p(grossPremium)

Normalize materiality within the current active dataset:

* Sectors normalized against sectors only
* Themes normalized against themes only
* All Stocks normalized against stocks only

tileSizeScore = pcrDeviation * normalizedMateriality

Rules:

* Extreme P/C with tiny dollar premium should not become massive.
* High dollar premium plus far-from-1.00 P/C should become large.
* Near-neutral P/C around 1.00 should be small/muted.
* Every visible item gets a positive value.
* Clamp extremes so one tile does not eat the whole page.
* Sort by tileSizeScore descending before layout.

Suggested:
value = max(tileSizeScore, 0.01)

Color:
Direction:

* P/C < 1.00 = green
* P/C > 1.00 = red
* near 1.00 = gray/neutral

Neutral band:

* 0.85 <= P/C <= 1.15 should be gray or very muted.

Intensity:

* based on pcrDeviation
* farther from 1.00 = stronger color
* closer to 1.00 = muted

2. Drag pans while zoomed.
3. Double-click or Reset button resets to full map.
4. Zoom must never cause page scrolling.
5. Zoom must not push the whole map into random blank space.
6. Zoom transform must be clamped so users cannot pan the map completely out of view.
7. At zoom = 1, the map is perfectly fitted.
8. Tooltip/click still works while zoomed.

If using d3.zoom:

* Apply transform to a single inner `<g>`.
* Use scaleExtent, for example [1, 12].
* Use translateExtent and extent based on measured width/height.
* Clamp pan to avoid losing the map off-canvas.
* Reset sets zoomIdentity.

Do not use an unbounded CSS transform wrapper that allows the map to drift off-screen.
