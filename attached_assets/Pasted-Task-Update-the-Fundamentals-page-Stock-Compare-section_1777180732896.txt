Formatting rules:
- currency: 122000000 => 122.00M
- price: 9.83 => $9.83
- percentDecimal: 0.084 => 8.4%
- percentAlready: -1.82 => -1.82%
- ratio: 1.07 => 1.07x
- number: 0.71 => 0.71
- null/undefined/NaN => N/A

Be careful:
priceChangePercent is already a percent number. Do not multiply by 100.
revenueGrowth, margins, ROE, ROA are decimals. Do multiply by 100 for display.
