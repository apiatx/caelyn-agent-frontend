Fix Stock Compare line chart not connecting datapoints

The Stock Compare chart on the Fundamentals page has data points and the tooltip works, but the actual colored lines are not connecting the datapoints. Fix this now.

Do not redesign the section. Do not touch backend unless absolutely necessary. This is a chart rendering/data-transform issue.

Problem

The chart shows individual datapoints on hover, but no visible line connects the points.

This means the backend data is making it to the frontend, but the chart data is probably not shaped correctly for Recharts LineChart.

Required fix

Normalize backend series into one shared row per fiscal year/date.

Correct chart data shape

The chart data should look like this:

[
  {
    year: "2021",
    INTT: 84500000,
    TRT: 49200000,
    NNBR: 430000000
  },
  {
    year: "2022",
    INTT: 116830000,
    TRT: 50700000,
    NNBR: 498740000
  },
  {
    year: "2023",
    INTT: 123000000,
    TRT: 53000000,
    NNBR: 470000000
  }
]

It should not look like this:

[
  { year: "2021", symbol: "INTT", value: 84500000 },
  { year: "2021", symbol: "TRT", value: 49200000 },
  { year: "2021", symbol: "NNBR", value: 430000000 }
]

That second shape causes Recharts lines to fail or render as scattered points because each Line dataKey="INTT" only sees values on isolated rows.

Implement this transform

Add or replace the chart transform with something like:

function buildCompareChartData(series: any[]) {
  const rowsByYear = new Map<string, any>();

  for (const s of series || []) {
    const symbol = s.symbol;
    if (!symbol || !Array.isArray(s.points)) continue;

    for (const point of s.points) {
      if (typeof point.value !== "number") continue;

      const year =
        point.fiscalYear?.toString() ||
        point.date?.slice(0, 4);

      if (!year) continue;

      if (!rowsByYear.has(year)) {
        rowsByYear.set(year, { year });
      }

      rowsByYear.get(year)[symbol] = point.value;
      rowsByYear.get(year)[`${symbol}Formatted`] = point.formatted;
      rowsByYear.get(year)[`${symbol}Name`] = s.name;
    }
  }

  return Array.from(rowsByYear.values()).sort(
    (a, b) => Number(a.year) - Number(b.year)
  );
}

Then use:

const chartData = buildCompareChartData(compareData?.series || []);

Only render symbols with at least 2 valid points

Before rendering lines, compute valid symbols:

const validSymbols = selectedSymbols.filter((symbol) => {
  const count = chartData.filter((row) => typeof row[symbol] === "number").length;
  return count >= 2;
});
