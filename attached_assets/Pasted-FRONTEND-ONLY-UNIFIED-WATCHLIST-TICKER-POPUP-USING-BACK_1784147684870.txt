Frontend repo only.

Backend endpoint is ready:

GET /api/watchlist/ticker-detail/{symbol}

Use this endpoint as the primary ticker detail data contract.

Goal:

The Watchlist ticker popup should become the single ticker detail surface.

Currently there are two competing experiences:

1. Ticker click modal with Overview / Fundamentals / News / AI Deep Dive
2. Right-hand Confluence detail drawer

We want one unified ticker modal.

Clicking a ticker anywhere on the Watchlist page should open the ticker detail modal.

The Confluence drawer content should move inside the ticker modal Overview tab.

PART 3 — DATA FETCHING
==================================================

On modal open, call:

GET /api/watchlist/ticker-detail/{symbol}

Use returned sections:

- company
- overview
- confluence_v42
- technical
- fundamentals
- fundamentals_source
- news
- direct_catalyst
- quote
- coverage

Do not call old modal upload/static payload for fundamentals.
Do not directly fetch FMP/RSS/Tradier from frontend.
Do not create new polling loops.

Quote fallback rule:

If backend returns:

quote.quote_status = "available"
→ use backend quote fields.

If backend returns:

quote.quote_status = "row_fallback_recommended"
→ use selected table row values for price/change/volume/rel vol when available.

If selected row also lacks quote data:
→ show "—".

Theme fallback rule:

If fundamentals.theme is null:
→ use selected row theme or confluence/theme value if available.

Missing values:

Render "—", not undefined/null/NaN.
