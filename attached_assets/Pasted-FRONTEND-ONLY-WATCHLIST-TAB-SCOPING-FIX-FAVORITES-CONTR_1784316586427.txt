PART 2 — FIX WATCHLIST ROW SOURCE SCOPING
==================================================

Create a clear separation between:

- activeWatchlistRows
- favoriteRows
- pendingOptimisticRows
- displayedRows

Rules:

If selected tab is Primary/custom watchlist:
displayedRows = rows that belong to that selected watchlist + pending optimistic rows for that same watchlist only

If selected tab is Favorites:
displayedRows = favoriteRows

Do not let favoriteRows leak into custom watchlists.

Do not let pending optimistic rows from one watchlist leak into another watchlist.

Pending optimistic rows must be scoped by watchlist_id.

If an optimistic row was added to Strong Bases, it should not appear in Primary or Favorites unless also favorited.

If an optimistic row was added to Primary, it should not appear in Strong Bases.
