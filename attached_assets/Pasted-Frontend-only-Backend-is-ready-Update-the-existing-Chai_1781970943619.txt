Backend compatibility note:
The backend confirmed curated anchor rows are now a superset of the existing `/api/bottlenecks/current` row shape.

Current row keys:
anchor_theme, anchor_ticker, bottleneckReason, bottleneck_score, bottleneck_ticker, bottleneck_type, change_percent_1d, company_name, country, discovery_sources, evidence, exchange, final_score, fundamental_score, lastUpdated, layer, marketCap, marketCapBucket, market_cap, momentum_score, options_score, revenueSignal, social_score, supply_chain_role, theme, theme_alignment_score, themes, volume_score

Curated rows include all of those plus extras:
anchor_key, anchor_name, confidence, evidence_grade, evidence_grade_reason, giant_anchors, last_curated_at, layer_name, manual_added, relationship_specificity, relationship_type, source_type, source_urls, tradingview_symbol, what_would_break_thesis, why_hidden, why_it_matters, why_now

So:

* Do not create a separate curated table renderer.
* Use the existing renderer.
* Use `bottleneck_ticker` as the matching/display ticker where the current page does.
* Use `tradingview_symbol` for charts only if the current chart component supports it; otherwise keep current chart behavior.
