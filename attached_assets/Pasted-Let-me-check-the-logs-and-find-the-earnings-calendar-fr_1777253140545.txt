Two bugs found and fixed. Here's what was causing the blank calendar:

Bug 1 — raw field removed from events
The V2 service's normalize function dropped the "raw": object field that the spec requires and the frontend uses. Any frontend code reading event.raw.someField would throw a JavaScript exception the moment it tried to render, silencing the whole component. Restored.

Bug 2 — countsByDate computed after the limit cut
With 469+ events on a single day and a limit=500, all subsequent days in the week were getting zero counts — so the calendar showed no dots for those days. The fix: build countsByDate and eventsByDate from the full event set first, then trim the flat events list. The calendar dots now reflect every FMP event in the range.
