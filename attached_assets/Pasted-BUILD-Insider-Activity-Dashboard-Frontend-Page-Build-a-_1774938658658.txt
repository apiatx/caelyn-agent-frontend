BUILD: Insider Activity Dashboard — Frontend Page

Build a new page at /app/stocks/insider-activity that displays an "Insider Activity" dashboard. This dashboard shows SEC Form 4 insider trading data ranked by a "conviction score" that measures how unusual each transaction is.

YOU ARE JUST DOING THE FRONTEND DESIGN. Do NOT fetch data yourself. Do NOT use any data API. Do NOT calculate scores. The backend handles ALL data fetching, scoring, and caching. You are a passthrough that displays data from the backend API.

=== DESIGN REFERENCE ===

This should look like the reference screenshots — a clean, professional data table with:
- Light/white background (NOT dark terminal style)
- Clean sans-serif font
- Green for buys, red/coral for sells
- Subtle row borders
- Professional financial terminal aesthetic

=== TOP SECTION: Summary Stats Bar ===

A horizontal bar across the top with 6 stat badges, each in a rounded rectangle with subtle background:
1. TOTAL TRANSACTIONS — icon: activity/chart icon, value: number formatted with commas (e.g., "32,291")
2. BUYS — icon: trending-up, value: green number (e.g., "2,305")
3. SALES — icon: trending-down, value: red/coral number (e.g., "29,986")
4. AVG BUY SCORE — icon: gauge/meter, value: number with 1 decimal (e.g., "64.2")
5. TOP BUY — icon: crown/star, value: ticker symbol in green (e.g., "TPL")
6. TOP SELL — icon: alert/flag, value: ticker symbol in red (e.g., "CRWV")
7. LAST REFRESH — icon: clock, value: date + time (e.g., "Mar 22, 10:51 AM")

Also add a "Refresh" button in the top-right corner with a refresh icon.

These values come from: GET /api/insider-activity/stats

=== HEADER: Title + Status ===

Left side:
- Icon (chart/activity icon)
- Title: "INSIDER ACTIVITY" in bold
- Subtitle: "SEC FORM 4 FILINGS" in smaller gray text
- Green dot + "LIVE" badge

Right side:
- Refresh button

=== QUICK FILTERS BAR ===

A row of pill/toggle buttons:
- "All" (with filter icon, selected by default, shows all transaction types)
- "High-Conviction Buys" (green dot icon, filters to buys with score >= 70)
- "High-Conviction Sells" (red dot icon, filters to sells with score >= 70)
- "Clustered" (link/chain icon, filters to transactions where cluster_size >= 2)
- "Large Trades" (diamond icon, filters to transactions where total_value >= 1,000,000)

Only ONE can be active at a time. The active one gets a filled/highlighted background.

=== FILTER DROPDOWNS ROW ===

Below the quick filters, a row of dropdown selects:
1. Search box: "Search ticker, company, insider..." — text input with search icon
2. Transaction type dropdown: "All Types" / "Buys" / "Sales" / "Exercises" / "Gifts"
3. Sector dropdown: "All Sectors" (populate with standard GICS sectors)
4. Timeframe dropdown: "1 Week" / "1 Month" / "3 Months" / "6 Months"
5. Score filter dropdown: "Any Score" / "80+" / "70+" / "60+" / "50+"
6. A "Filtered:" label on the right showing if any filters are active

=== MAIN DATA TABLE ===

Columns (left to right):
1. SCORE — The conviction score (0-100), displayed as a number with a small horizontal colored bar next to it:
   - 80-100: green bar, green text
   - 60-79: amber/yellow bar
   - 40-59: gray bar  
   - 0-39: light gray bar
   The bar length is proportional to the score (100 = full width of the cell).

2. TICKER — Stock symbol in bold monospace font, colored green for buys, red for sells. Clickable.

3. COMPANY — Company name, truncated with "..." if too long

4. INSIDER — Insider name, truncated with "..." if too long

5. ROLE — Insider title (CEO, Director, 10% Owner, etc.), truncated

6. DATE — Transaction date formatted as "Mon DD, YY" (e.g., "Mar 6, 26"). Sortable.

7. TYPE — "Buy" or "Sale" or "Exercise" or "Gift" displayed as a colored pill/badge:
   - Buy = green background, white text
   - Sale = red/coral background, white text
   - Exercise = blue background
   - Gift = gray background

8. SHARES — Number of shares, formatted with commas (e.g., "200,000"). Sortable.

9. PRICE — Price per share in USD (e.g., "$18.42")

10. VALUE — Total value, formatted with K/M suffix and colored:
    - Green text for buys (e.g., "$3.7M")
    - Red text for sells
    Sortable.

11. % CHG — Percentage change since the transaction date. Green for positive, red for negative (e.g., "+200.0%" in green, "-55.0%" in red). Sortable.

12. CLUSTER — Number showing how many insiders filed for this company in a 14-day window. Display as a colored circle/badge with the number inside:
    - 1-2: gray circle
    - 3-5: blue circle
    - 6+: purple circle

13. CONTEXT — Tags displayed as small text labels separated by spaces. Tags include things like: "open-market sell", "11 insiders", "large trade", "C-suite", "major stake change"

Column headers should be sortable (click to sort). Show a small up/down arrow next to the currently sorted column. Default sort: Score descending.

Table rows should:
- Have alternating very subtle background colors (white / very light gray)
- Highlight on hover
- Be clickable — clicking a row opens the detail side panel

=== DATA FETCHING ===

The page should fetch data from these backend endpoints:

1. Page load: GET /api/insider-activity?sort=score&order=desc&limit=50
2. Stats bar: GET /api/insider-activity/stats
3. When a row is clicked: GET /api/insider-activity/detail/{accession_number}
4. When filters change: GET /api/insider-activity?type={type}&timeframe={timeframe}&min_score={score}&search={search}&sort={sort}&order={order}&limit=50&offset={offset}
5. Refresh button: POST /api/insider-activity/refresh

=== PAGINATION ===

At the bottom of the table, show:
- "Showing 1-50 of 32,291 results"
- Previous / Next buttons
- Page number display

Load 50 rows at a time. Use offset-based pagination with the API's offset parameter.

=== STATE MANAGEMENT ===

Use React state to manage:
- Current filter selections (type, sector, timeframe, score, search query)
- Sort column and direction
- Selected transaction (for detail panel)
- Loading state
- Current page / offset
- Stats data

=== AUTO-REFRESH ===

- Auto-refresh the data every 5 minutes (300 seconds)
- Show a countdown or "last updated X seconds ago" near the LIVE badge
- Don't auto-refresh if the user has the detail panel open (to avoid disrupting their view)

=== RESPONSIVE BEHAVIOR ===

- On smaller screens, hide the CONTEXT and CLUSTER columns
- The detail side panel should overlay on mobile (full width)
- The stats bar should wrap to 2 rows on mobile

=== LOADING STATES ===

- Show skeleton loading rows while data is being fetched
- Show a spinner on the Refresh button while refresh is in progress
- Show "No results found" message if filters return empty results

=== IMPORTANT NOTES ===

- ALL data comes from the backend API. The frontend does ZERO calculations.
- ALL scores are pre-calculated by the backend.

- The frontend is a pure display/passthrough layer.
- Format numbers nicely: commas for thousands, K/M suffix for large values, 2 decimal places for prices.
- Format dates as "Mon DD, YY" (short month, day, 2-digit year).
- Color coding: green = buy/positive, red = sell/negative, amber = caution, gray = neutral.
