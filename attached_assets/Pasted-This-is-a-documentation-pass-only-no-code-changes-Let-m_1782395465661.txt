5. Cache / Coalescing Proof
Only physical HTTP calls that reach TradierProvider._get() increment the budget counter. Three mechanisms prevent double-counting:

get_quotes (per-ticker cache)

# get_quotes(): cache-first before _get() is ever called
hit = cache.get(f"tradier:quote:sym:{sym}")
if hit is not None:
    result.append(hit)   # ← returns here; _get() never called
    ...
if not missing:
    return result        # 100% hit: zero budget consumed

get_option_expirations (coalescing via _EXPIRY_FUTURES)

if symbol in _EXPIRY_FUTURES:
    _coalesced_expiry_count += 1
    return await asyncio.shield(_EXPIRY_FUTURES[symbol])  # ← short-circuit; _get() not called

The second (and Nth) concurrent caller for the same symbol awaits the already-in-flight future. Only the first caller reaches _get() and counts against the budget.

get_option_chain (coalescing via _CHAIN_FUTURES)

if coalesce_key in _CHAIN_FUTURES:
    _coalesced_chain_count += 1
    return await asyncio.shield(_CHAIN_FUTURES[coalesce_key])  # ← short-circuit; _get() not called

Same pattern. Lifetime coalesce counts are exposed in the rate-status response under coalesced_expiry_requests_lifetime and coalesced_chain_requests_lifetime.

Conclusion: cache hits + coalesced waiters = zero budget cost. Only unique, physical HTTP calls to Tradier advance the per-lane counter.
