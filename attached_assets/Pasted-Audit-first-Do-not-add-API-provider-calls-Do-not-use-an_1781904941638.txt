Sorting:
Fix Stage column sorting in the Themes page Market Performance table.

1. S1 Base
2. S1-2 Watch
3. S2 Breakout
4. S2-S3 Advance
5. S3 Momentum
6. S3-S4 Top
7. S4 Decline
8. missing/null/unknown last

When the user clicks Stage descending, rows should sort:

1. S4 Decline
2. S3-S4 Top
3. S3 Momentum
4. S2-S3 Advance
5. S2 Breakout
6. S1-2 Watch
7. S1 Base
8. missing/null/unknown last

Important:
Missing/null/unknown stages should always sort last, both ascending and descending.

Do not alphabetically sort stages.
Do not sort by old score.
Do not sort by badge color.
Use a deterministic rank map.
