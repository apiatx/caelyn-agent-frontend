This is a surgical frontend implementation for renaming "Sector Rotation" to "Sectors" and upgrading the page behavior. Do NOT redesign the app. Audit first, then implement carefully.

Goal:
Update the current "Sector Rotation" page into a "Sectors" page that:
1. is renamed everywhere in the frontend UI,
2. shows the strongest sector(s) over key timeframes,
3. displays the key stocks in those winning sector(s),
4. clearly surfaces momentum leaders, bottleneck/enabling names, and anchor giants,
5. supports expandable TradingView chart embeds for displayed stocks,
6. fixes the "agent analysis" button flow,
7. loads and displays the last saved analysis after refresh until the user manually generates a new one.

Critical product intent:
- This page should show where the real action is.
- Usually one sector stands out, but sometimes there may be multiple.
- The displayed stocks should not be a random list; they should be meaningful.
- The user should immediately see:
  - winning sector(s)
  - why they are winning
  - the top names in them
  - financials
  - catalysts
  - expandable TradingView chart iframe
  - saved/latest agent analysis
- No brittle hacks. Use the backend contract cleanly.
