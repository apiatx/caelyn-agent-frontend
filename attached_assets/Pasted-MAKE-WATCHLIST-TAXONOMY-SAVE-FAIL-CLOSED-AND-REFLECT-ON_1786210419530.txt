KNOWN DANGEROUS CLIENT PATTERN

The original hierarchical editor code used behavior equivalent to:

const data = await r.json().catch(() => ({}));
if (!r.ok) throw ...

This is NOT safe.

An HTTP 200 HTML response from a SPA fallback can therefore become:

r.ok === true
JSON parse fails
data becomes {}
client proceeds as though save succeeded

That exact failure mode previously happened when the Express PUT proxy was missing.

Remove any remaining ability for a non-JSON 2xx response to count as a successful taxonomy save.
