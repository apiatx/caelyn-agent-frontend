Goal:
Update Portfolio Dashboard so imported options trades are visible and usable without mixing them into stock/equity sections.

Add a Portfolio Dashboard view toggle:
- All
- Trades
- Options

Definitions:
- All = show stock/equity sections and options sections
- Trades = show only stock/equity portfolio sections
- Options = show only options sections

Do NOT:
- parse option contracts in frontend
- calculate option P&L in frontend
- call Tradier/options providers from frontend
- hardcode option symbols
- put options in stock Open / Partially Closed / Fully Closed sections
- use old /api/portfolio/upload-csv
- break stock CSV categorization that now works
- break Portfolio Terminal

Data sources:
Use backend data from:
- GET /api/portfolio/holdings
and import result from:
- POST /api/portfolio/transactions/import-csv
