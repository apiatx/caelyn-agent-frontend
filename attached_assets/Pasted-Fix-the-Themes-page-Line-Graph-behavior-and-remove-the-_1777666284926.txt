Fix the Themes page Line Graph behavior and remove the duplicate timeframe toggle from Market Performance view only.

Context:
The unified Themes page card now has 3 view modes:
- Market Performance
- Relative Strength
- Line Graph

The Line Graph view looks good visually, but it is wrong functionally:
Changing the selected timeframe button between 1D / 7D / 30D / YTD / 1Y does not change the line graph. The chart is always showing the same x-axis buckets:
1D → 7D → 30D → YTD → 1Y

That means the selected timeframe toggle is meaningless in Line Graph view right now.

Also:
In Market Performance view, the timeframe button bar is duplicative because the table already has sortable 1D / 7D / 30D / YTD / 1Y columns. Remove the timeframe toggle only from Market Performance view.

Do not change backend.
Do not change Earnings.

- If selected timeframe = 7D:

- If selected timeframe = 30D:
  - The line graph should show performance progression across the 30-day window.
- If selected timeframe = YTD:

- If selected timeframe = 1Y:
