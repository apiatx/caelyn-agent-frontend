PART 2 — BACKEND CONTRACT

The response contains:

earnings_intelligence: {
  schema_version: 1,
  earnings_history: EarningsQuarter[],
  reaction_summary: ReactionSummary,
  ratings: {
    consensus: RatingsConsensus | {},
    monthly_distribution: MonthlyRatingDistribution[],
    recent_actions: RatingAction[],
    price_target: PriceTarget | null,
    price_target_summary: PriceTargetSummary | null
  },
  sec_filings: null,
  source_status: {
    earnings_fetched_at: string | null,
    ratings_fetched_at: string | null,
    history_bars_source: string | null,
    sec_filings_omitted_reason: string | null,
    errors: Record<string, string>,
    coverage: {
      has_earnings_history: boolean,
      has_reactions: boolean,
      has_ratings_consensus: boolean,
      has_rating_actions: boolean,
      has_rating_history: boolean,
      has_price_targets: boolean
    }
  }
}

Each earnings_history record can contain:

- date
- timing
- timing_confidence
- timing_source
- fiscal_year
- fiscal_period
- report_status
- join_method
- eps_actual
- eps_estimate
- eps_surprise_pct
- eps_surprise_amount
- eps_qoq
- eps_yoy
- revenue_actual
- revenue_estimate
- revenue_surprise_pct
- revenue_surprise_amount
- revenue_qoq_pct
- revenue_yoy_pct
- price_reaction

price_reaction can contain:

- baseline_date
- baseline_close
- first_reaction_session
- sessions_used
- opening_gap_pct
- reaction_1d_pct
- reaction_3d_pct
- reaction_5d_pct
- max_upside_5d_pct
- max_drawdown_5d_pct
- bars_source
- calculation_method
- calculation_confidence
- reactions_final

Important semantics:

- Percentages are already percentage points.
- 16.47 means 16.47%, not 0.1647%.
- Revenue values are raw dollars.
- EPS values are dollars per share.
- earnings_history is sorted most recent first.
- Null means unavailable. Never display null as zero.
- reactions_final=false means the reaction window is preliminary.
- timing_confidence is usually inferred_low.
- sec_filings is currently null and must not be rendered.
- Quarterly future estimates are not available.
- Do not fabricate projected quarterly bars.

Create accurate TypeScript interfaces based on the real deployed response.

Do not type fields as always present when live records can return null.
