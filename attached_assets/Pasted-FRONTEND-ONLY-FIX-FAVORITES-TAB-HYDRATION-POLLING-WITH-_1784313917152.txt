PART 4 — FIX HYDRATION POLLING STOP CONDITION
==================================================

After single add or batch add, poll hydration status until all four categories are terminal.

Categories:

quote
technical
fundamentals
options

Terminal statuses:

done
error
no_options

Non-terminal statuses:

pending
running
queued
null
undefined

Rules:

- Do not stop polling just because the ticker appears in the table.
- Do not stop polling when quote/technical/fundamentals are done if options is still pending.
- Do not stop polling when options is pending unless max duration is reached.
- Invalidate/refetch watchlist query on meaningful status change.
- Invalidate ticker detail cache for the symbol when fundamentals or options become terminal.
- Avoid duplicate polling intervals per symbol.

Suggested polling:

- every 5 seconds
- hard stop after 3–5 minutes
- if max time expires while options is still pending, leave a subtle “Options queued” status and stop aggressive polling

Do not poll forever.
