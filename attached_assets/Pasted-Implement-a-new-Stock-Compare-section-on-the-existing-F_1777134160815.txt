Important Design Notes

Do not use AI reasoning for the core comparison. This should be deterministic financial data from FMP.

AI can be added later as a button like:

Analyze Compare

But the first version should be fast, clean, and data-native.

This feature should feel like:

“YCharts-style comparison, but inside CaelynAI.”

Not like another chat answer. The page itself should do the work.
