Goal:
Add a new bottom tab on the Watchlist page called:

High Conviction Trade Zone

This tab should show tickers with the best mix of trading indicators flashing, specifically:

* strong options signal / options score
* high VolX
* high Vol / Market Cap
* constructive early stage: S1 Base, S1-2 Watch, or S2 Breakout

This is different from `High Conviction Investment Zone`.

* Investment Zone = fundamentals + early stage
* Trade Zone = flow/volume/liquidity signal confluence + early stage

Eligibility:
A ticker qualifies for `High Conviction Trade Zone` only if all of these are true:

1. Constructive early stage:
   Use:
   row.stage_analysis?.label || row.stage2_breakout?.label

Allowed stages:

* S1 Base
* S1-2 Watch
* S2 Breakout

Do not include:

* S2-S3 Advance
* S3 Momentum
* S3-S4 Top
* S4 Decline

2. At least two of these three signal groups are strong:

* Options signal
* VolX
* Vol / Market Cap

3. It is not totally missing all trade-signal fields.

Signal scoring:
Calculate percentiles within the currently active saved watchlist only.

Examples:

* Primary percentiles use Primary tickers only
* Close Watch/Favorites percentiles use only Close Watch/Favorites tickers
* future saved tabs use only their own tickers

Do not compare Close Watch against all Primary tickers.

Options signal score:
Use existing options score if available.

Preferred:

* options_score / opt_score / flow_score >= 50 qualifies as strong
* > = 70 is very strong
* > = 85 is elite

If no numeric options score exists, use available options fields:

* bullish / unusual / high activity option signal = positive
* low activity / no signal = weak
* high option volume percentile = positive
* high OI percentile = positive
* constructive put/call ratio if available
* extreme IV alone should not qualify as bullish; tag it as risk

VolX score:
Use existing VolX / relative volume field.
Strong:

* VolX >= 2.0
  or
* top 15% VolX among active watchlist rows

Elite:

* VolX >= 5.0
  or
* top 5% VolX among active watchlist rows

Vol / Market Cap score:
Use existing Vol / Market Cap field if available.
Strong:

* top 15% among active watchlist rows

Elite:

* top 5% among active watchlist rows

If Vol / Market Cap is not directly available but volume and market cap exist, compute:
volMc = volume / market_cap

Do not compute it if either volume or market cap is missing/invalid.

Stage score:

* S2 Breakout = strongest
* S1-2 Watch = strong setup
* S1 Base = early setup

Conviction score:
Create a deterministic `tradeConvictionScore` using:

* options score / options signal strength
* VolX percentile
* Vol / Market Cap percentile
* stage score
* penalty for missing key fields

Suggested weight:

* Options signal: 40%
* VolX: 25%
* Vol / Market Cap: 25%
* Stage: 10%

Do not overfit. Keep it simple and explainable.

Only show the best setups:
This tab should not list every ticker.
Only include tickers that pass eligibility and have real signal confluence.

Suggested gate:

* allowed stage
* tradeConvictionScore >= 60
* at least two strong signal groups

If too many rows appear, tighten by requiring:

* options score > 50
  or
* top 15% VolX and top 15% Vol / Market Cap

Do not loosen rules automatically just to fill the tab.
