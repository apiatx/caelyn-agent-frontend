Endpoint Contract (Backend is deployed and live)
All three endpoints now return the same scoring fields. Use whichever your page already calls — no need to switch endpoints.

1. Market Screener — GET /api/predict/markets
Query params:

limit — number of markets (default 200, max 500)
tag — category filter: Sports, Crypto, Politics, Tech, Geopolitics, Finance, Economy, Culture, Election (exact casing)
min_volume — minimum 24h volume filter (default 0)
Response shape:

{
  "count": 200,
  "markets": [ <market objects> ]
}

2. Signals Dashboard — GET /api/predict/signals
Response shape:

{
  "top_movers":      [ <market objects> ],
  "top_edges":       [ <market objects> ],
  "whale_markets":   [ <market objects> ],
  "surging_markets": [ <market objects> ],
  "top_by_volume":   [ <market objects> ],
  "top_by_liquidity":[ <market objects> ],
  "summary": {
    "total_volume_24h": 0,
    "total_liquidity": 0,
    "avg_spread_pct": 0,
    "edge_count": 0,
    "whale_active_count": 0,
    "surging_count": 0
  }
}

3. Signal Engine / Recommendation Cards — GET /api/predict/recommendations
Response shape:

{
  "best_bet_now":                          [ <market objects> ],
  "best_yes_setup":                        [ <market objects> ],
  "best_no_setup":                         [ <market objects> ],
  "best_momentum_continuation":            [ <market objects> ],
  "best_mean_reversion_candidate":         [ <market objects> ],
  "best_whale_follow":                     [ <market objects> ],

Field	Type	Example

no_pct	number	0–100

Prophetik Signal Engine Scores (0–100 scale)
Field	Type	Notes
composite_score	number	Overall Prophetik score, 0–100

flow_score	number	Volume flow quality, 0–100

Critical Units & Gotchas
price_change_* fields are percentage points, not decimals. price_change_1d: 15.1 means YES odds moved +15.1 percentage points in 24h. Do NOT multiply by 100.

spread_pct is already a percentage. spread_pct: 0.5 means 0.5% spread. Do NOT multiply by 100.

yes_pct and no_pct are 0–100. yes_pct: 27.8 = 27.8%. yes_price is the raw decimal (0.278).

trap_risk_score is inverted — higher is worse. 0 = no trap risk, 100 = high trap/manipulation risk. If displaying as a "health" bar, invert it.

whale_activity is a boolean, not a score. There is no numeric whale score — it's true/false only.

momentum_label casing. Values use underscores: "strong_up", "stale_pinned" — not spaces or camelCase.

top_mispricings will be empty. This bucket returns [] currently — don't show it or show "No mispricings detected."

signal-changes starts empty on cold boot. GET /api/predict/signal-changes returns { changes: [], change_count: 0 } until the backend has accumulated multiple cache snapshots (usually 5–15 minutes after first request). Show a loading/warming state.

Do NOT call Gamma API directly from the browser. CORS blocks it. All Polymarket data must go through the backend.

Category tag names are case-sensitive. Use exact casing: Sports, Crypto, Politics, Tech, Technology, Geopolitics, Finance, Economy, Culture, Election. Tags Trending, Breaking, New, Mentions return 0 markets — hide them or show "No markets."
