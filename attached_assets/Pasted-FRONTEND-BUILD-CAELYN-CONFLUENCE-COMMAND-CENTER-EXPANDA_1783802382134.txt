==================================================
TAB 1 — ACTIONABLE SETUPS
==================================================

Purpose:

Show what is closest to actionable now.

Rank rows using frontend-only logic:

1. Actionability state priority:
READY / BUY / ADD first
WAIT_FOR_RETEST / WAIT_FOR_BREAKOUT next
WATCH / EARLY_WATCH next

2. Trade Alignment score descending

3. Entry constructive states ahead of broken/extended states

4. Catalyst / Options confirmation as tie breakers

Show 8–12 cards max.

Each card must show:

Ticker
Company if available
Actionability badge
Trade Alignment score
Investment Alignment score if available
Entry state
Catalyst score
Catalyst source
Theme Policy boost if present
Options state/score if present
Primary theme

Example:

MRVL
Actionability: WATCH
Trade: 81
Investment: 78
Entry: WAIT_FOR_RETEST
Catalyst: 78 · RSS + Theme Policy
Policy: Semiconductors +12.5
Options: Bullish pressure

Why:
Strong trade setup and policy tailwind, but entry is not ready yet.

Do not say only:

“Bullish.”
