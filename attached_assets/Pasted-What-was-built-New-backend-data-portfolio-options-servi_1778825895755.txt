What was built
New: backend/data/portfolio_options_service.py
A standalone async service, scan_portfolio_options(), that holds the canonical options scoring logic — shared by both the terminal and the HTTP endpoint. No duplication.

Three-layer cache strategy:

Whole-portfolio cache portfolio_opts_scan_v1:{holdings_sig} — 300s TTL
Per-ticker cache portfolio_opts:{sym} — 300s TTL (reuses existing key)
Master screener cache rows (already scored by TradierFlowEngine — best quality, zero calls)
Live Tradier scan for anything not in any cache (batch quote → semaphore(6) concurrent chain scans)
Same definitions as the Options Screener page:

IV: smv_vol (ORATS smoothed) → iv field fallback
EM: ATM straddle (c_mid + p_mid) / price × 100 → percentage (e.g. 3.96 = 3.96%)
Signal: UNUSUAL CALL FLOW / UNUSUAL PUT FLOW / HIGH IV / OPTIONS ACTIVITY / LOW ACTIVITY
Score: vol_score(35) + iv_score(20) + dir_score(20), max 75
Updated: backend/data/caelyn_terminal.py
