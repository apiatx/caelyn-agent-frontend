IMPORTANT SEMANTIC RULE

Do not label an upcoming percentage as “Beat” or “Miss.”

Before results are reported, actual earnings do not exist, so a beat/miss percentage cannot be calculated truthfully.

For upcoming earnings, display:

- EPS analyst estimate

After results are reported, the existing reported-results UI should continue showing actual beat/miss percentages.

PART 4 — GROWTH CALCULATION

Prefer explicit backend growth fields when available.

If the backend provides no explicit expected-growth percentage but provides the correctly matched prior-year-quarter actual, calculate:

EPS expected growth:

((current EPS estimate / prior-year-quarter EPS actual) - 1) × 100

Revenue expected growth:

((current revenue estimate / prior-year-quarter revenue actual) - 1) × 100

Only calculate when:

- both values are finite
- the prior-year value belongs to the matching fiscal quarter
- the denominator is valid

Do not calculate EPS growth from a zero or negative prior-year EPS using the normal percentage formula.

For negative-to-positive EPS transitions, display:

Profit expected

For positive-to-negative transitions, display:

Loss expected

For negative-to-less-negative transitions, display:

Loss narrowing

For negative-to-more-negative transitions, display:

Loss widening

Do not display misleading EPS growth percentages in these cases.

PART 5 — NULL HANDLING
